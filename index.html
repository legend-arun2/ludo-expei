Ludo Learners

Four agents play Ludo knowing only which moves are legal. Each one keeps its own memory and learns from nothing but whether it won.

Give orders

One order per line, or separate them with a semicolon. Run them with the button or Ctrl+Enter.

    What the agents understand
    • Who: red green yellow blue all or red and blue, then a colon.
    • always and never set a preference to +6 or -6 and lock it. prefer and avoid set +3 or -3 and leave it free to learn. End an order with locked or unlocked to choose.
    • set capture to 2.5, lock capture, unlock capture, forget capture, forget all.
    • Styles: be aggressive, be cautious, be racer.
    • Preferences: leave the yard, capture, safe square, home column, home, flee danger, risk, pair, lead. Join several with "and".
    • Rules: rule exact home off, rule extra turns off, rule three sixes off, rule safe squares off, rule exit 1,6.

    Rules, changeable while playing

    A change applies from the next roll and is remembered. The agents keep what they learned under the old rules.

    What the agents start with

    • The rules only: the game hands each agent its legal moves and it picks one.
    • For each move it can see plain facts, such as whether it captures or lands on a safe square. It is never told which facts are good.
    • Every preference starts at 0, so a new agent plays at random.
    • After each game it is told one thing, won or lost, and shifts its preferences toward what it did in wins and away from what it did in losses.
    • You can edit any preference with its slider, lock it so games stop changing it, or forget it.
    • Moves you make in a seat do not change that agent's memory.

    Rules in this game

    • Roll a 6 to bring a token out. Exact roll needed to get home.
    • Landing on a lone opponent sends it back to its yard, except on start and star squares.
    • Two tokens of one colour on a square cannot be captured. They do not block.
    • Roll again after a 6, a capture, or getting a token home. A third 6 in a row loses the turn.
    • First to get all four tokens home wins.
